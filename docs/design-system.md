# THE HARPER 디자인 시스템

출처: 「THE HARPER Brand Identity Guide v1.0」(2026.09, 로고·컬러·서체) 확정 값. 홈페이지와 모바일앱 모두 이 문서를 기준으로 삼는다. 가이드 원본은 로컬 `docs/brief/`에 두고 저장소에는 올리지 않는다.
코드에서는 [src/styles/tokens.css](../src/styles/tokens.css)의 CSS 변수로 같은 값을 쓴다. 값이 바뀌면 두 파일을 함께 고친다.

### 확장 팔레트(시즌·캡슐 전용, 선택 사용)
브랜드 가이드 03장. 시즌 컬렉션이나 캡슐 드롭처럼 한정된 곳에만 골라 쓰는 보조색이다. 메인 로고와 핵심 UI에는 쓰지 않는다. 팬톤 값은 인쇄용 근사값이라 화면에는 HEX만 쓴다.

| 이름 | 영문 | HEX | CSS 변수 | CMYK | PANTONE(Solid Coated, 근사) |
| --- | --- | --- | --- | --- | --- |
| 블라섬 블러시 | blossom blush | `#E8B4B8` | `--color-blush` | C0 M22 Y21 K9 | 4064 C (ΔE≈2.0) |
| 밀크티 베이지 | milk tea beige | `#D8C3A5` | `--color-beige` | C0 M10 Y24 K15 | 4248 C (ΔE≈1.8) |
| 제이드 위스퍼 | jade whisper | `#8FA693` | `--color-jade` | C14 M0 Y11 K35 | 2457 C (ΔE≈3.3) |
| 테라코타 클레이 | terracotta clay | `#C97B5C` | `--color-terracotta` | C0 M39 Y54 K21 | 7591 C (ΔE≈4.4) |
| 앰버 골드 | amber gold | `#C9A15C` | `--color-amber` | C0 M20 Y54 K21 | 4024 C (ΔE≈4.5) |

쓸 때 지킬 것
- 시즌·캡슐 콘텐츠(예: 캡슐 드롭 배너, 시즌 룩북)에만 쓴다. 헤더·버튼·배지·로고 같은 핵심 UI에는 쓰지 않는다.
- 바탕색으로만 쓴다. 글자는 잉크로 올린다. 흰 글자는 다섯 색 모두 대비가 3.3:1 이하라 쓰지 않는다.
- 테라코타 클레이 위에는 잉크 글자도 3.7:1이라 본문 크기를 못 올린다. 24px 이상 큰 글자나 숫자만 둔다.
- 블라섬 블러시는 안틱 로즈와 거의 같은 자리다. 한 화면에 둘을 같이 쓰지 않는다.
- 다섯 색은 세기가 비슷해 위계를 못 만든다. 강조는 여전히 안틱 로즈 한 가지로 한다.

| 바탕 | 잉크 글자 대비 | 흰 글자 대비 |
| --- | --- | --- |
| 블라섬 블러시 | 6.7:1 | 1.8:1 |
| 밀크티 베이지 | 7.0:1 | 1.7:1 |
| 제이드 위스퍼 | 4.6:1 | 2.6:1 |
| 테라코타 클레이 | 3.7:1 | 3.3:1 |
| 앰버 골드 | 5.0:1 | 2.4:1 |

기본 조합
- 바탕은 그라운드, 글자는 잉크.
- 주요 버튼은 잉크 바탕에 흰색 글자. 제출 버튼만 코코아 브라운.
- 안틱 로즈는 배지·강조처럼 작은 면적에만 쓴다. 바탕색이나 본문 글자색으로 쓰지 않는다.

대비(접근성)
| 조합 | 대비 | 판정 |
| --- | --- | --- |
| 잉크 글자 / 그라운드 바탕 | 약 11.4:1 | 본문 가능 |
| 그라운드 글자 / 잉크 바탕 | 약 11.4:1 | 본문 가능 |
| 안틱 로즈 글자 / 그라운드 바탕 | 약 2.1:1 | 글자색으로 쓰지 않음 |
| 잉크 글자 / 안틱 로즈 바탕 | 약 5.5:1 | 배지 글자 가능 |

## 2. 타이포그래피

| 용도 | 서체 | 쓸 수 있는 굵기 | 홈페이지에서 쓰는 굵기 | CSS 변수 |
| --- | --- | --- | --- | --- |
| 워드마크, 헤드라인 | Cormorant Garamond | 300 / 400 / 500 / 600 | 400(워드마크), 500(히어로 제목, 모바일 메뉴) | `--font-display` |
| UI, 본문(국문), 태그 | Noto Sans KR | 300 / 400 / 500 / 700 | 300 / 400 / 500 / 700 | `--font-body` |

- Cormorant Garamond는 워드마크와 헤드라인 전용이다. 본문이나 버튼에는 쓰지 않고, 두 서체의 역할을 섞지 않는다.
- 워드마크는 Cormorant Garamond Regular(400)에 자간을 넓게 준다. 홈페이지 헤더·푸터 로고는 자간 +8%.
- 웹에서는 두 서체 모두 Google Fonts에서 불러온다. 둘 다 오픈소스라 상업적 사용이 가능하다.
- Noto Sans KR 300(Light)은 브랜드 가이드 v1.0에는 없던 굵기로, 홈페이지 작업(2026-09-30, hy0909)에서 추가했다. 헤더 메뉴, 히어로 소개 글, Focus Area 소개 글, 섹션명처럼 본문보다 한 단계 가볍게 보여야 하는 곳에 쓴다.
- [확인 필요] 다국어(영/일/중) UI 서체는 플랫폼 시스템 기본 서체를 함께 쓰는 것을 권장. 확정되면 여기에 서체 이름을 적는다.

## 3. 로고

| 구분 | 이름 | 색 | 쓰는 곳 |
| --- | --- | --- | --- |
| 메인 로고(1순위) | Cocoa Reverse Lockup | 코코아 브라운 바탕 + 안틱 로즈 워드마크 | SNS 프로필, 앱 스플래시, 메인 배너처럼 브랜드 노출이 큰 곳 |
| 보조 로고 | Classic Wordmark(하프 스트링 라인) | 잉크 | 인쇄물, 패키징 인서트, 공식 문서, 브랜드 스토리 화면 |
| 단색 워드마크 | Wordmark · Ink Brown | 잉크 | 밝은 바탕, 오프화이트 바탕 위 |
| 단색 워드마크 | Wordmark · Antique Rose | 안틱 로즈 | 브라운 같은 어두운 바탕 위 |

- 메인 로고의 바탕색과 글자색은 정해진 두 색 조합 그대로 쓴다.
- 클래식 워드마크 아래 이중 선은 '하프 현(harp string)'을 뜻하는 요소로, 브랜드 이름의 뜻을 설명하는 자리에 쓴다.
- 홈페이지 헤더·푸터는 밝은 바탕이라 잉크 단색 워드마크를 쓴다. Cormorant Garamond 400, 자간 +8%, 대문자.

여백과 크기
- 로고 둘레에는 워드마크 대문자 높이(cap height)의 1배 이상 여백을 둔다.
- 디지털 최소 폭 120px, 인쇄 최소 폭 25mm. 이보다 작게 줄이지 않는다.

하지 말 것
- 가로·세로 비율을 늘리거나 줄이지 않는다.
- 정해진 색 외의 색으로 바꾸지 않는다.
- 그림자, 외곽선, 그러데이션 같은 효과를 넣지 않는다.
- 대비가 낮은 바탕(그레이 위 로즈, 로즈 위 브라운 등) 위에 올리지 않는다.
- 워드마크 서체를 다른 서체로 바꾸지 않는다.

로고 파일 위치: `public/logo/` [확인 필요 — 원본 파일을 받으면 채운다]

## 4. 아직 정해지지 않은 것

브랜드 가이드에 없어서 홈페이지 작업 때 정해야 하는 값. 정하면 이 문서와 tokens.css에 함께 적는다.

- 간격 단위(spacing scale)
- 그림자
- 글자 크기 단계(제목 1·2·3, 본문, 작은 글씨)
