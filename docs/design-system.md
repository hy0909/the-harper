# THE HARPER 디자인 시스템

출처: 「THE HARPER Brand Identity Guide v1.0」 확정 값. 홈페이지와 모바일앱 모두 이 문서를 기준으로 삼는다.
코드에서는 [src/styles/tokens.css](../src/styles/tokens.css)의 CSS 변수로 같은 값을 쓴다. 값이 바뀌면 두 파일을 함께 고친다.

## 1. 컬러

### 주요색
| 역할 | 이름 | HEX | CSS 변수 | 쓰는 곳 |
| --- | --- | --- | --- | --- |
| Key | 코코아 브라운 | `#6F4A3A` | `--color-key` | 메인 로고 배경, 접촉 폼 제출 버튼(드물게) |
| Ground | 그라운드 | `#FAF9F6` | `--color-ground` | 배경, 여백 |
| Ink | 잉크 | `#3A362F` | `--color-ink` | 본문 텍스트, 헤더, 주요 UI, 클래식 워드마크 |
| Point | 안틱 로즈 | `#D6A3AB` | `--color-point` | PICK 배지, 강조 요소 |

### 보조색(그레이)

기본 조합
- 바탕은 그라운드, 글자는 잉크.
- 주요 버튼은 잉크 바탕에 흰색 글자. 제출 버튼만 코코아 브라운.
- 안틱 로즈는 배지·강조처럼 작은 면적에만 쓴다. 바탕색이나 본문 글자색으로 쓰지 않는다.

대비(접근성)
| 조합 | 대비 | 판정 |
| --- | --- | --- |
| 잉크 글자 / 그라운드 바탕 | 약 11.4:1 | 본문 가능 |
| 그라운드 글자 / 잉크 바탕 | 약 11.4:1 | 본문 가능 |
| 안틱 로즈 글자 / 그라운드 바탕 | 약 2.1:1 | 글자색으로 쓰지 않음 |
| 잉크 글자 / 안틱 로즈 바탕 | 약 5.5:1 | 배지 글자 가능 |

## 2. 타이포그래피

| 용도 | 서체 | 굵기 | CSS 변수 |
| --- | --- | --- | --- |
| 워드마크, 헤드라인 | Cormorant Garamond | 500 / 600 | `--font-display` |
| UI, 본문(국문) | Noto Sans KR | 400 / 500 / 700 | `--font-body` |

- Cormorant Garamond는 로고, 스플래시, 대제목에만 쓴다. 본문이나 버튼에는 쓰지 않는다.
- 웹에서는 두 서체 모두 Google Fonts에서 불러온다.
- [확인 필요] 다국어(영/일/중) UI 서체는 플랫폼 시스템 기본 서체를 함께 쓰는 것을 권장. 확정되면 여기에 서체 이름을 적는다.

## 3. 로고

| 구분 | 이름 | 쓰는 곳 |
| --- | --- | --- |
| 메인 로고 | Cocoa Reverse Lockup | 스플래시, 앱 아이콘, SNS 프로필 |
| 보조 로고 | Classic Wordmark | 인쇄물, 공식 문서, 브랜드 스토리 화면 |

하지 말 것
- 정해진 크기보다 작게 줄이지 않는다.
- 비율을 바꾸거나 색을 바꾸지 않는다.
- 대비가 낮은 바탕 위에 올리지 않는다.
- 상세 규칙은 브랜드 가이드 01~02장을 따른다.

로고 파일 위치: `public/logo/` [확인 필요 — 원본 파일을 받으면 채운다]

## 4. 아직 정해지지 않은 것

브랜드 가이드에 없어서 홈페이지 작업 때 정해야 하는 값. 정하면 이 문서와 tokens.css에 함께 적는다.

- 간격 단위(spacing scale)
- 그림자
- 글자 크기 단계(제목 1·2·3, 본문, 작은 글씨)

## 5. 홈페이지에서 정한 부품 값

홈페이지 작업(2026-09-29)에서 정한 값. `src/styles/site.css`가 기준이고, 바꾸면 여기도 같이 고친다.

### 버튼

| 항목 | 값 |
|---|---|
| 글꼴 | Noto Sans KR 500, 15px |
| 기본 크기 | 안쪽 여백 8px 16px, 높이 41px 이상 |
| 큰 크기(`btn--lg`) | 안쪽 여백 12px 28px, 높이 49px 이상 |
| 모서리 | 6px |
| 마우스 올림 | 색만 바뀐다. 채움 버튼은 한 단계 진하게, 테두리 버튼은 흰색으로 채우고 글자는 잉크. 위치 이동·그림자 없음 |

종류: 주요(잉크 바탕·흰 글자), 강조(코코아 바탕·흰 글자, 협업 문의·보내기), 테두리(투명 바탕·회색 테두리), 흰 테두리(어두운 사진 위).
